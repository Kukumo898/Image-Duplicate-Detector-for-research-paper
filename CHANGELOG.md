# Changelog

Significant public changes are recorded here. Dates refer to repository releases rather than independent software certification.

## [1.0.0] - 2026-10-23

### Initial Windows release

- Published a packaged Windows x64 application through GitHub Releases.
- Documented three inspection modes visible in the application: batch image inspection, PDF/Word document image inspection and two-image comparison.
- Documented inspection history and a local research image library.
- Added evidence visualization for potential local image reuse and similarity review.
- Published setup instructions and a manual-review warning for scientific image integrity screening.

### Availability and limitations

- Downloadable Windows application: see the [v1.0.0 release](https://github.com/Kukumo898/Image-Duplicate-Detector-for-research-paper/releases/tag/v1.0.0).
- Application source code is **not yet published** in this repository.
- No platform support beyond the packaged Windows x64 release is claimed.
- Detection accuracy, false-positive rates and minimum hardware requirements have not been independently established in this changelog.
