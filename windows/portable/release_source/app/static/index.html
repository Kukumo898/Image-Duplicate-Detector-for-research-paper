使用与判读

图片查重系统是一套图像核验辅助工具，科研结论由了解实验的研究者给出。

01

选择合适的核验方式

批量查重

上传实验原图或导出的图版，检测本次文件间的重复，也可与已积累的课题组图库比对。

文档查重

上传 PDF 或 DOCX，解析其中可提取的图像。默认自动拆分组合图，并比较同一图版内的面板；可在原图位置视图核对标签。文档内部的图像结构可能影响提取。DOCX 无可靠页码，Office 矢量图建议先转 PDF；扫描页与嵌套图版需额外检查。

双图对比

对两张指定图像进行针对性核验，适合复查可疑局部。该模式不检索历史图库。

02

读懂证据，不只看分数

严格与均衡

严格策略采用更保守的规则，优先降低误报；均衡策略适合扩大线索筛查范围。阈值不等于经本课题组数据验证的准确率。

区域与特征连线

证据视图可标记匹配区域和特征点。规则纹理、重复条带、坐标轴、标尺与文字都可能带来干扰，应回到原始图像确认。

多区域与荧光通道

同一对图像可出现多条区域线索。通道提示表示共享了相应色彩分量，不代表整张 Merge 图相同；同组单通道与 Merge 的共享通常是正常呈现，需结合实验组与图注复核。

三种复核状态

「待复核」保留待查线索；「已确认」表示人工确认相似关系；「已排除」记录不构成问题的线索。建议添加判断依据。

03

科研使用边界

优先导入原始图像

避免多次压缩、截图与极低分辨率输入。自动拆分支持组合图的跨面板比对，但可能遗漏没有明显边界的面板。单个连续面板内部的复制粘贴尚未覆盖。对于 Western blot、凝胶图与高度规则的细胞纹理，应特别留意算法误判与遗漏。

先用已知样本验证

正式使用前，准备课题组自己的已知重复和已知非重复样本，评估误报与漏报。内置示例仅用于演示操作，不是准确率验证。

保存完整复核链

人工备注和导出报告应连同原始数据归档。本系统不判定学术不端；未检出也不能作为图像绝对无问题的证明。
