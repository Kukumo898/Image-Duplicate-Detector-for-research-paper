# 图鉴 · Windows x64 便携版

## 启动与网页加速开关

1. 将整个“图鉴”文件夹解压到本机普通用户可写的位置（支持中文和空格）。不要直接在 ZIP 内运行。
2. 双击唯一启动入口 **启动图鉴.bat**。就绪后自动打开本机网页；重复双击复用同一实例。首次默认开启加速，不需要安装 Python、配置开发环境或联网下载依赖。
3. 网页“运行状态”附近有 **加速模式** 开关。开启时复用已有单图特征；关闭时走原计算路径，不代表降低精度。开关会正常退出旧后端、启动并验证新后端，网页短暂重连；选择只在真正成功后保存。上传选择和未保存的复核备注保留，不需刷新网页。
4. 上传、任务或保存尚未完成时会拒绝切换，请等待完成后再点击；不会排队为以后偷偷切换。实际缓存尚未初始化、已命中及真实回退提示与模式分开显示。

## 正常关闭

双击 **关闭图鉴.bat**。窗口确认正常关闭后，任务、来源、图库、复核状态和中文备注仍保留。忙碌时会拒绝关闭，等待工作完成后重试。

**关闭网页不等于停止后台。软件使用中不要移动、删除或直接复制用户资料目录。** 不要用任务管理器强行结束后立即搬迁资料。

## 数据与整体迁移

- `runtime/python`：随包 Python、依赖和原生运行库，不是用户数据。
- `user_data/data`：任务数据库、上传原件、解码图、缩略图与遮罩，是需要保护的资料。
- `user_data/settings.json`：最后成功生效的加速模式偏好。
- `user_data/cache`：可重建加速缓存；`user_data/logs` 和 `user_data/records`：运行日志及内部身份。
- `backups`：用户手动生成的备份 ZIP。干净发行包没有用户任务和验收素材。

迁移已使用的资料：

1. 在原位置双击“关闭图鉴”，确认正常关闭。
2. **整体复制“图鉴”文件夹**（含 `user_data`）到新位置或另一台兼容电脑，不要只复制数据库主文件，也不要混合两个位置的资料。
3. 在新位置双击“启动图鉴.bat”。首次会校验正常退出凭据和资料引用，在副本中重新绑定路径并校验完整性，失败保留原资料，不会悄悄初始化空库。原位置的实例不会被新位置控制。
4. 任务、来源、图片、图库、中文备注及报告重建资料保留，最后模式选择保留。旧会话与控制令牌不会继承；缓存目录身份变化时安全重建，首次查重可能重新计算。

请先为重要资料做备份。迁移的安全暂存会额外需要约一份用户资料的可用磁盘空间。不要同时从两个复制位置继续积累同一套资料后再手工合并。此版本不会自动导入旧日常版的真实库。

## 离线备份与恢复

先正常关闭，再双击 **备份本机数据.bat**。备份写入本包 `backups`，包含一致性数据库快照、上传来源、图片、缩略图、遮罩、图库与复核资料、报告重建资料和模式偏好；不包含可重建缓存、进程身份和日志。未上传的外部实验资料，以及另存到其他位置的报告文件，应另行备份。

双击 **恢复本机数据（新目录）.bat**，选择同版备份 ZIP。它只恢复到新的空目录，校验文件哈希和数据库引用，不覆盖已有资料。窗口显示新的完整软件文件夹；它自带随包运行时，请双击其中同一个 **启动图鉴.bat**。不要寻找旧“恢复后入口”或两个模式 BAT。恢复包与原包独立，如另一个包占用配置端口，请先用它自己的关闭入口正常退出；软件不会控制陌生服务。备份恢复会复制软件运行时，需预留相应磁盘空间。

## 遇到问题

- 端口被占用、进程归属或资料身份不符时，入口明确报错；不会停止无关进程，也不会切换到空库。网页实际地址以启动窗口为准，不固定指向原机器旧服务。
- 切换失败时网页说明已确认状态。先保留资料，等待失败恢复完成；必要时双击“关闭图鉴”，再双击“启动图鉴”。不要通过直接编辑环境变量冒充切换成功。
- 入口错误：包根 `launcher_errors.log`；后端日志：`user_data/logs`。不要把 `records` 中的控制令牌公开发送。
- 随包运行时缺失或损坏时，请重新解压完整 ZIP；入口不会借用外部 Python 或自动安装依赖。

支持 Windows x64、本机可写目录；加速缓存沿用本地 NTFS 目录身份要求。这里不承诺所有 Windows 版本或所有电脑已实测。当前发行的实际验收与跨机限制见包外《实现与验收报告》。检测引擎与缓存键/失效原则未改变；此便携化验收不是新的科学准确率认证。
